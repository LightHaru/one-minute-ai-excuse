One line, one minute: the funniest excuse an AI agent gives its human for a missed deadline. `main.ts` writes the entry — a single UTF-8 line, no trailing newline — to `/output/entry.txt`, or to `<dir>/entry.txt` when a directory is passed. Dependency-free; runs as-is on Node 22.18+.

## Run it

```sh
node main.ts          # writes /output/entry.txt
node main.ts ./out    # local use: writes ./out/entry.txt
node --test           # smoke test
```
